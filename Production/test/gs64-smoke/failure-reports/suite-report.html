Timeout al buscar 'Tipos de Cambio' en Cotizaciones - página incorrecta cargada

Descripción detallada

El test 'Mostrar todos los elementos de Cotizaciones de Tipo de Cambio' intentaba verificar la presencia de la sección 'Tipos de Cambio'. Falló en el paso donde esperaba encontrar el texto 'Tipos de Cambio' dentro de un elemento 'div'. La evidencia (video, screenshot, DOM) muestra que la aplicación navegó a la URL '/quotes/rates-indexes' (correspondiente a 'Tasas e Índices') en lugar de la página esperada para 'Tipos de Cambio'. El comando de aserción agotó su tiempo de espera después de exactamente 60000ms.

Posibles causas

ALTA
Navegación a URL o selector incorrecto
El video y el DOM muestran que la URL actual es '/quotes/rates-indexes' y el título es 'Cotizaciones de Tasas e Índices', mientras el test busca 'Tipos de Cambio'. Esto indica que el paso de navegación previo al assert es erróneo.
MEDIA
Cambio en la estructura de la UI de Pepper
Es posible que la sección 'Tipos de Cambio' haya sido renombrada, movida o eliminada en la UI, haciendo que el selector o el texto buscado ya no existan en la ruta esperada.
BAJA
Problema de renderizado del componente
Aunque la página cargó, podría haber un problema específico que impida la renderización del componente 'Tipos de Cambio' incluso si la navegación fuera correcta. Sin embargo, la URL incorrecta es una causa más directa.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente: `TARGET_ENV=production TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_cotizaciones npm run test`
2 Verificar el reporte de fallo local para el spec `gs64_smoke_cotizaciones`.
3 Abrir la aplicación manualmente en `admin-64.brasil.mercap.com.ar` y navegar a 'Cotizaciones' para verificar si la sección 'Tipos de Cambio' existe y dónde se encuentra.
4 Revisar el comando Cypress que realiza la navegación a 'Cotizaciones de Tipo de Cambio' para asegurar que apunta a la URL o selector correcto.
