Descripción detallada

El test intentaba mostrar todos los elementos de 'Cotizaciones de Tipo de Cambio'. Falló en el paso donde se esperaba encontrar el texto 'Tipos de Cambio' dentro de un elemento 'div'. La aserción agotó el tiempo de espera después de 60000ms. La evidencia del video y el DOM al momento del fallo muestra que la aplicación se encuentra en la página '/quotes/rates-indexes' que corresponde a 'Cotizaciones de Tasas e Índices', y el texto 'Tipos de Cambio' no está presente.

Posibles causas

ALTA
Navegación a página incorrecta
El log de Cypress y la URL en el video (`/quotes/rates-indexes`) confirman que el test llegó a la sección 'Tasas e Índices', no a 'Tipos de Cambio', donde se esperaba el texto.
MEDIA
Cambio en la UI o ruta de navegación
Es posible que la ruta o la forma de acceder a 'Cotizaciones de Tipo de Cambio' haya cambiado, o que el texto 'Tipos de Cambio' ya no se presente de la misma manera en la UI.
BAJA
Selector o texto de aserción incorrecto
Aunque menos probable dada la navegación a una página diferente, podría haber una discrepancia entre el selector o el texto esperado y el real si el test hubiera llegado a la página correcta.
