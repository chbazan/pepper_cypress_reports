Timeout 60s: Modal 'Alta de Tasa' bloquea interacción con fila de tabla al intentar editar

Descripción detallada

El test intentaba iterar sobre las tasas financieras y hacer click en 'Editar' en cada una. El fallo ocurrió cuando Cypress intentó interactuar con una fila de la tabla (`<tr class="table-body-row">`) para realizar la acción de edición. Sin embargo, un modal titulado 'Alto de Tasa' (para agregar una tasa) estaba abierto y cubriendo el elemento de la tabla, impidiendo la interacción. Cypress reintentó la acción por 60 segundos antes de agotar el timeout. La duración total del test fue de 120562ms, lo que indica que el test estuvo bloqueado por un tiempo considerable.

Posibles causas

ALTA
Lógica de la aplicación: Acción 'Editar' abre modal incorrecto
El test está intentando 'Editar' una tasa, pero el modal visible es 'Alto de Tasa' (para agregar). Esto indica que la acción de edición está invocando el modal incorrecto o que el modal de alta se abrió previamente y no se cerró.
MEDIA
Fallo en paso previo del test
Dado que 'testIsolation: false', un test anterior o un paso previo en este mismo test podría haber abierto el modal 'Alto de Tasa' y no lo cerró correctamente, dejando la UI en un estado inesperado.
BAJA
Bug de UI: Modal persistente o superpuesto
Aunque menos probable que un error de lógica, podría haber un bug visual donde el modal se renderiza incorrectamente o no se cierra, permaneciendo sobre la tabla y bloqueando la interacción.

Pasos de Troubleshooting

1 Reproducir el spec fallido en el ambiente de staging: TARGET_ENV=staging TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_tasas npm run test
2 Abrir la aplicación manualmente en production/br-gs64 y navegar a 'Tasas' para observar el comportamiento de los modales al intentar editar o agregar una tasa.
3 Revisar el video del fallo para identificar el momento exacto en que aparece el modal 'Alto de Tasa' y si hay alguna acción previa que lo desencadene.
4 Inspeccionar el DOM en el navegador durante la ejecución manual para verificar la visibilidad y el z-index del modal en relación con la tabla.
