Timeout 60s: Elemento 'Tipos de Cambio' no encontrado en la sección de Cotizaciones.

Descripción detallada

El test 'Cotizaciones > Cotizaciones de Tipo de Cambio > Mostrar todos los elementos de Cotizaciones de Tipo de Cambio' intentaba verificar la presencia del elemento 'Tipos de Cambio'. El fallo ocurrió cuando Cypress no pudo encontrar un div con dicho contenido, agotando el defaultCommandTimeout de 60000ms. La evidencia del DOM y el video muestran que la aplicación cargó la sección 'Cotizaciones de Tasas e Índices' en la URL '/quotes/rates-indexes', en lugar de la esperada para 'Tipos de Cambio'.

Posibles causas

ALTA
Error de navegación o URL incorrecta
El video y el DOM muestran que la URL cargada es `/quotes/rates-indexes` y el contenido es 'Tasas e Índices', mientras que el test busca 'Tipos de Cambio'. Esto sugiere que el clic o la navegación previa llevó a la página equivocada.
MEDIA
Cambio en la estructura de la UI
El selector `div` con el texto 'Tipos de Cambio' podría haber sido modificado o eliminado si la funcionalidad de 'Tipos de Cambio' fue movida o renombrada en la UI, aunque la URL actual no corresponde a esa sección.
BAJA
Problema de renderizado del componente
Es posible que el componente de 'Tipos de Cambio' no se haya renderizado debido a un error interno de la aplicación, pero la evidencia apunta más a una navegación incorrecta a otra sección de cotizaciones.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente: TARGET_ENV=production TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_cotizaciones.cy.js npm run test
2 Abrir la aplicación manualmente en production/br-gs64 y navegar a 'Cotizaciones > Cotizaciones de Tipo de Cambio' para verificar si la sección existe y se renderiza correctamente.
3 Revisar el comando Cypress en `cypress/support/commands/cotizaciones.commands.js` línea 1668 para entender la secuencia de navegación y el selector exacto utilizado.
4 Verificar si hay un paso previo de clic o navegación que debería llevar a la URL de 'Tipos de Cambio' y si ese paso falló silenciosamente.
