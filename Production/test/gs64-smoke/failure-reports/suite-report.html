Descripción detallada

El test 'Cotizaciones > Cotizaciones de Tipo de Cambio > Mostrar todos los elementos de Cotizaciones de Tipo de Cambio' estaba en ejecución. Falló en el paso donde esperaba encontrar el texto 'Tipos de Cambio' dentro de un elemento 'div'. El error indica un timeout después de exactamente 60000ms, lo que significa que el elemento nunca fue encontrado en el DOM dentro del tiempo de espera predeterminado. La evidencia del DOM al momento del fallo muestra que la aplicación cargó la página 'Cotizaciones de Tasas e Índices' (URL: /quotes/rates-indexes), no la sección esperada de 'Cotizaciones de Tipo de Cambio'.

Posibles causas

ALTA
Navegación incorrecta o URL errónea.
El DOM muestra la URL '/quotes/rates-indexes' y el título 'Cotizaciones de Tasas e Índices', mientras el test busca 'Tipos de Cambio'. Esto sugiere que el paso de navegación previo llevó a la página equivocada.
MEDIA
Cambio de UI o selector obsoleto.
Si la navegación fue correcta, el texto 'Tipos de Cambio' podría haber sido renombrado o movido, haciendo que el 'cy.contains' falle. Sin embargo, la URL actual es el factor más fuerte.
BAJA
Componente no renderizado o error de carga.
Aunque menos probable dado que otra sección se cargó correctamente, podría haber un error en la carga del componente específico de 'Tipos de Cambio' si la navegación fue correcta.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente: TARGET_ENV=production TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_cotizaciones.cy.js npm run test

3 Abrir la aplicación manualmente en production/br-gs64 y navegar a 'Cotizaciones > Cotizaciones de Tipo de Cambio' para verificar si la sección existe y el texto 'Tipos de Cambio' es visible.
4 Revisar el comando Cypress en 'cotizaciones.commands.js:1668' para asegurar que la navegación a la URL correcta (ej. '/quotes/exchange-rates') se realiza antes de buscar el elemento.
