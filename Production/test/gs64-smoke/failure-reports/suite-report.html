Error UI en Tasas: Modal 'Alta de Tasa' cubre tabla al intentar editar

Descripción detallada

El test intentaba recorrer las tasas existentes y hacer click en 'Editar' en cada una. El fallo ocurrió cuando Cypress intentó interactuar con una fila de la tabla (`<tr class="table-body-row">`) para realizar un 'mouseover', pero un modal con el título 'Alta de Tasa' (`<div class="p-3 p-md-4 modal-header">`) estaba cubriendo el elemento. La operación de Cypress agotó su tiempo de espera de 60 segundos intentando interactuar con el elemento cubierto, resultando en un tiempo total de test de 120 segundos.

Posibles causas

ALTA
Elemento no visible (overlay)
El mensaje de error indica directamente que el elemento `<tr>` está siendo cubierto por el `modal-header`, y el video/screenshot confirman la presencia del modal 'Alta de Tasa' sobre la tabla.
ALTA
Flujo de test incorrecto o estado inicial inesperado
El test busca 'Editar' tasas, pero el modal abierto es de 'Alta de Tasa'. Esto sugiere que el test no está en el estado esperado o que una acción previa abrió el modal incorrectamente.
MEDIA
Cambio de UI que abre modal automáticamente
Es posible que un cambio reciente en la interfaz de usuario haga que el modal de 'Alta de Tasa' se abra automáticamente al cargar la página o al realizar una acción no relacionada.

Pasos de Troubleshooting

1 Reproducir el spec fallido en el ambiente de staging: TARGET_ENV=staging TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_tasas npm run test
2 Abrir la aplicación manualmente en production/br-gs64 y navegar a 'Tasas Financieras' para observar si el modal 'Alta de Tasa' aparece automáticamente o bajo qué condiciones.
3 Revisar los pasos del test que preceden al fallo para identificar si alguna acción está abriendo el modal de forma inesperada.
4 Inspeccionar el DOM en el Cypress Test Runner en el momento del fallo para verificar la visibilidad y el z-index del modal y la tabla.
