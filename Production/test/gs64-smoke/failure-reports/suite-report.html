Módulo Tasas - Timeout por elemento cubierto por modal inesperado al editar tasas

Descripción detallada

El test 'Recorrer todas las tasas haciendo click en Editar' intentaba interactuar con filas de una tabla, específicamente con un `cy.trigger('mouseover')`. El fallo ocurrió porque un modal titulado 'Alta de Tasa' apareció inesperadamente y cubrió las filas de la tabla, impidiendo la interacción. Cypress agotó el `defaultCommandTimeout` de 60000ms esperando que el elemento fuera interactuable. El HAR no muestra errores de red ni solicitudes lentas.

Posibles causas

ALTA
Modal inesperado cubriendo elementos
El error de Cypress indica explícitamente que el elemento `<tr>` está cubierto por un `div` de modal. El video y el screenshot confirman la presencia del modal 'Alta de Tasa' en el momento del fallo.
MEDIA
Fallo en un paso previo del test
Es posible que una acción anterior en el test haya abierto el modal 'Alta de Tasa' o no lo haya cerrado correctamente, dejando la UI en un estado inesperado para el paso actual.
BAJA
Cambio inesperado en la UI de Pepper
Un cambio reciente en la interfaz de usuario podría haber introducido este modal en un flujo donde no debería aparecer, aunque el error es muy específico sobre el elemento cubierto.

Pasos de Troubleshooting

1 Reproducir el spec fallido: TARGET_ENV=production TARGET_CLIENT=br-gs64 MODE=only SPEC=gs64_smoke_tasas npm run test
2 Abrir la aplicación manualmente en https://admin-64.brasil.mercap.com.ar/instruments/rates-indexes/financial-rates y verificar si el modal 'Alta de Tasa' aparece sin interacción o si alguna acción lo dispara inesperadamente.
3 Revisar los comandos de Cypress que preceden al `cy.trigger()` en el `BEFORE EACH` o en el `it` block para identificar la acción que pudo haber abierto el modal.
4 Verificar si hay algún spinner o overlay que no se ocultó antes de intentar interactuar con la tabla.
