Posibles causas

ALTA
Ticker RESA15 no existe o no está configurado
El mensaje de error 'No se encontró RESA15 después de 5 intentos' y la ausencia de errores de red (HAR limpio) sugieren que la API respondió correctamente pero sin datos para RESA15, indicando que el ticker no está presente o accesible en el sistema para el ambiente y mercado especificados.
MEDIA
Problema en la lógica de filtrado/búsqueda de la UI
Aunque la API devuelva una respuesta válida (posiblemente vacía), podría haber un error en cómo la UI procesa o muestra los resultados de la búsqueda, impidiendo que el ticker sea visible incluso si existiera en el backend.
BAJA
Datos de prueba desactualizados
El test espera que RESA15 exista, pero los datos de prueba o la configuración del ambiente de producción podrían haber cambiado, haciendo que el ticker ya no sea válido o esté disponible para la búsqueda.
