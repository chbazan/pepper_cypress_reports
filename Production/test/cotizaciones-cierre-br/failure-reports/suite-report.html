Fallo al buscar ticker RESA15 en cotizaciones de securities B3: no se encontraron resultados

Descripción detallada

El test "Validación de cotizaciones B3 Admin & APIs Brasil > Cotizaciones de Securities > Guardar la cotización de cierre del ticker RESA15" intentaba encontrar y potencialmente guardar la cotización de cierre para el ticker RESA15. El fallo ocurrió después de iniciar sesión y navegar a la página de administración de cotizaciones, específicamente al intentar buscar el ticker "RESA15". El video y la captura de pantalla muestran que el ticker fue ingresado, el mercado B3 seleccionado, y la búsqueda ejecutada, pero la tabla de resultados permaneció vacía, mostrando "No hay información para mostrar", lo que llevó al error personalizado "No se encontró RESA15 después de 5 intentos". Todos los requests de red completaron exitosamente sin errores (4xx/5xx) ni lentitud.

Posibles causas

ALTA
Ticker RESA15 no existe o no tiene cotizaciones para la fecha actual
El error explícito "No se encontró RESA15 después de 5 intentos" y la tabla vacía en la UI, junto con la ausencia de errores de red (4xx/5xx) o requests lentos, sugieren que la búsqueda se ejecutó correctamente pero no encontró datos. Esto es común si el ticker no está cargado o no tiene datos para el día en el ambiente de producción.
MEDIA
Problema de sincronización de datos entre la fuente de cotizaciones (B3) y Pepper
Aunque no hay errores de red directos, podría existir un problema en el proceso de ingesta o ETL que impide que los datos de RESA15 se muestren en la UI, incluso si el ticker existe en la fuente original.
BAJA
Error en la lógica de búsqueda o filtrado de la UI
El video muestra que el ticker se ingresa y se selecciona correctamente del dropdown. La ausencia de errores de red sugiere que la solicitud al backend se hizo y el backend respondió sin errores, lo que hace menos probable que la UI esté filtrando incorrectamente un conjunto de resultados que debería haber sido devuelto.

Pasos de Troubleshooting

1 Verificar manualmente en admin.brasil.mercap.com.ar/administrative si el ticker RESA15 existe y tiene cotizaciones para la fecha actual.
2 Reproducir el spec fallido localmente con TARGET_ENV=production TARGET_CLIENT=br-gs32 MODE=only SPEC=cotizaciones_cierre_br.cy.js npm run test para observar el comportamiento en vivo.
3 Inspeccionar el HAR del test fallido para el request de búsqueda de cotizaciones y verificar el payload de la respuesta del backend.
4 Consultar la API de Investments o Appraiser directamente para RESA15 en el ambiente de producción para la fecha del test.
5 Si el ticker debería existir, verificar los logs de ingesta de datos de B3 para el ambiente de producción.
