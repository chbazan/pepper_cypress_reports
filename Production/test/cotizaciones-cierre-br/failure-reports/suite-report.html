Descripción detallada

El test "Inversión del bono ARTRA1 con la cotización de cierre esperada" estaba ejecutando un flujo para validar cotizaciones de bonos ANBIMA en el módulo de Investments. El fallo ocurrió durante una llamada a la API para registrar una inversión (POST /api.brasil.mercap.com.ar/investments). El test esperaba un código de estado 201 Created, pero la API devolvió un 503 Service Unavailable. La duración del test de 1441ms indica una respuesta inmediata del servidor con el error.

Posibles causas

ALTA
Problema temporal en el servicio de Investments
El error 503 es una respuesta directa del servidor, indicando que no pudo procesar la solicitud. La duración corta del test (1441ms) refuerza que fue una respuesta inmediata del servidor, no un timeout de Cypress.
MEDIA
Despliegue reciente o mantenimiento del backend
Los errores 503 son comunes durante despliegues o mantenimientos, donde el servicio puede estar temporalmente inactivo o reiniciándose.
BAJA
Sobrecarga del servidor de Investments
Aunque es una posibilidad para un 503, la duración tan corta no sugiere una espera prolongada por recursos, sino una falla más directa.
