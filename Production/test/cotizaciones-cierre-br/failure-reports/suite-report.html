Fallo al buscar ticker RESA15 en cotizaciones de cierre B3: no se encontraron resultados.

Descripción detallada

El test "Guardar la cotización de cierre del ticker RESA15" estaba ejecutando el flujo para buscar y guardar una cotización de cierre para el ticker RESA15 en el mercado B3 de Brasil. El fallo ocurrió después de que el test inició sesión, navegó a la página de administración de cotizaciones, ingresó "RESA15" en el campo de búsqueda, seleccionó la opción del dropdown y hizo clic en buscar. La interfaz de usuario mostró consistentemente "No hay información para mostrar" tras cada uno de los 5 intentos de búsqueda, lo que llevó a un error personalizado del comando Cypress indicando que el ticker no fue encontrado.

Posibles causas

ALTA
Ticker RESA15 no existe o no tiene cotizaciones para la fecha.
El video muestra que la UI devuelve "No hay información para mostrar" después de cada intento de búsqueda, y el error explícito es "No se encontró RESA15 después de 5 intentos". Esto sugiere que el ticker no está disponible o no tiene datos en el sistema.
MEDIA
Problema en la lógica de búsqueda del backend.
Aunque el frontend interactúa correctamente con el campo de búsqueda y el HAR no reporta errores de red (0 fallidos), el backend podría estar fallando en su consulta a la base de datos o en la lógica de filtrado, resultando en un conjunto de resultados vacío.
BAJA
Datos de test desactualizados o ambiente incorrecto.
Es posible que RESA15 fuera un ticker válido en el pasado o en otro ambiente, pero ya no lo es en 'production/br-gs32' o para la fecha de búsqueda implícita en el test.

Pasos de Troubleshooting

1 Abrir la aplicación manualmente en admin.brasil.mercap.com.ar/administrative y buscar el ticker RESA15 en el mercado B3 para la fecha actual.
2 Verificar si el ticker RESA15 existe en la base de datos de producción para el mercado B3 y si tiene cotizaciones de cierre.
3 Si el ticker existe, monitorear los logs del backend (Appraiser/Investments) al realizar la búsqueda manual para identificar posibles errores internos que no se reflejan en el HAR.
4 Revisar la implementación del comando `buscarYGuardarCotizacion` en `cypress/support/commands/cotizaciones.commands.js` para entender cómo se determina que un ticker 'no se encontró'.
5 Ejecutar el test en un ambiente de staging (`TARGET_ENV=staging TARGET_CLIENT=br-gs32 MODE=only SPEC=cotizaciones_cierre_br npm run test`) para ver si el comportamiento se replica.
