Posibles causas

ALTA

El `TypeError: Cannot read properties of null (reading 'money')` en `cotizaciones.commands.js` después de un `POST` a `/appraiser` sugiere fuertemente que la API devolvió un objeto `null` donde se esperaba un valor con la propiedad `money`.
MEDIA
Bug en el comando Cypress `cotizaciones.commands.js`
Aunque la API devuelva `null`, el comando en la línea 558 debería manejar este caso (e.g., con validación de existencia) para evitar un `TypeError` y proporcionar un mensaje de error más claro.
BAJA
Datos de test desactualizados para RESA15
Si los datos esperados en el fixture no coinciden con lo que la API devuelve, podría llevar a un procesamiento incorrecto, aunque un `TypeError` de `null` es más indicativo de un campo faltante o nulo en la respuesta de la API.
