Descripción detallada

El test 'Guardar la cotización de cierre del ticker RESA15' busca una cotización en el ABM de Securities. Tras ingresar 'RESA15' y seleccionarlo, la tabla de resultados no se puebla, mostrando el mensaje 'No hay información para mostrar'. El test falla al esperar por el icono de refresco (`span.glyphicon-refresh`), que se ubica dentro de la fila de resultados, agotando el timeout de 60000ms porque la fila nunca se renderiza. El HAR confirma que las llamadas a la API devuelven status 200 OK, sin errores de red.

Posibles causas

ALTA
Inexistencia de datos de cotización para el ticker RESA15 en el ambiente de producción para la fecha consultada.
El HAR muestra una respuesta 200 OK del backend y el video muestra una tabla vacía. Este es el comportamiento esperado si no hay datos, pero el test asume que sí los hay, causando el timeout.
BAJA
Bug en la lógica del frontend que no renderiza la fila de resultados a pesar de que la API devuelva datos.
Menos probable, ya que no hay errores de consola y el HAR no muestra fallos. Sin embargo, un problema de parsing de la respuesta en el cliente podría causar este síntoma.
BAJA
El selector `span.glyphicon-refresh` fue modificado o eliminado en un deploy reciente.
El problema principal parece ser la ausencia de la fila de resultados completa, no solo el icono. Si la fila se renderizara, es más probable que el fallo fuera otro.

Pasos de Troubleshooting

1 Ejecutar el spec localmente para confirmar la reproducibilidad: `TARGET_ENV=production TARGET_CLIENT=br-gs32 MODE=only SPEC=gs32/cotizaciones_cierre_br npm run test`.
2 Acceder manualmente al ambiente de producción de Pepper Brasil y buscar la cotización de 'RESA15' para la fecha del test para verificar si existen datos.
3 Inspeccionar la respuesta del request `POST` a `/administrative` en el HAR adjunto para confirmar que el payload de respuesta está efectivamente vacío.
4 Si otros tickers sí devuelven datos, inspeccionar el DOM para verificar si el selector `span.glyphicon-refresh` sigue siendo válido.
5 Consultar con el equipo de backend si se esperan datos para el ticker RESA15 en el ambiente de producción y si hubo cambios recientes en la API de cotizaciones.
