TypeError al procesar cotización RESA15 de Appraiser API - propiedad 'money' nula

Descripción detallada

El test 'Valuación del bono RESA15 con la cotización de cierre esperada' estaba validando cotizaciones de B3 usando la Appraiser API. El fallo ocurrió después de una solicitud POST exitosa (status 200) a 'https://api.brasil.mercap.com.ar/appraiser', cuando el comando de Cypress intentó leer la propiedad 'money' de la respuesta de la API. El video y la captura de pantalla muestran que la UI cargó correctamente y búsquedas previas de otros tickers fueron exitosas. El HAR indica que no hubo solicitudes de red fallidas o lentas, lo que sugiere que la API respondió, pero con un objeto 'null' o sin la propiedad 'money' esperada, causando un error de tiempo de ejecución en la lógica de procesamiento del test.

Posibles causas

ALTA
Appraiser API devuelve datos incompletos/nulos para RESA15.
El error 'Cannot read properties of null (reading 'money')' ocurre después de un 'POST 200' a '/appraiser', lo que sugiere que la API respondió, pero con un objeto 'null' o sin la propiedad 'money' esperada, lo que el test no manejó.
MEDIA
Bug en el comando 'cotizaciones.commands.js'.
Aunque la API sea la causa principal, el comando de Cypress en la línea 558 no está validando adecuadamente la estructura de la respuesta de la API antes de intentar acceder a 'response.money'.
BAJA
Datos de test desactualizados para RESA15.
Podría ser que el test espera una estructura de datos que ya no es válida para RESA15, aunque el error 'null' es más indicativo de una ausencia total del valor.
