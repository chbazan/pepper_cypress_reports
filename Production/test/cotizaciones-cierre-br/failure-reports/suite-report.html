MEDIA

La UI o la API de Pepper podría estar calculando o mostrando un valor incorrecto para PETR17, lo que lleva a la discrepancia con el valor esperado del test. Esto requeriría una investigación del backend o frontend.
BAJA

Aunque la red no mostró errores, podría haber una desincronización entre la fuente de datos de la UI y la fuente de datos usada para el valor esperado del test (e.g., Appraiser vs. Investments), resultando en valores diferentes para el mismo instrumento.
