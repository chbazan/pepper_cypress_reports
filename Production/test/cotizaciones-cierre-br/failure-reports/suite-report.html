Posibles causas

ALTA
Lógica de test incorrecta para estado sin datos
El video muestra 'No hay información para mostrar' y el HAR no registra fallos de red. Es probable que el backend haya devuelto un resultado vacío para RESA15, y el test espera un spinner que no se muestra en este escenario.
MEDIA
Fallo en el renderizado del spinner
Si el spinner 'span.glyphicon-refresh' debería aparecer incluso para cargas rápidas o resultados vacíos, entonces hay un bug en la UI que impide su renderizado.
BAJA
Ticker RESA15 sin cotizaciones en el ambiente
Si RESA15 realmente no tiene cotizaciones en el ambiente de 'production/br-gs32', la UI muestra 'No hay información para mostrar' correctamente, pero el test no maneja este caso.

3 Verificar en los logs de la aplicación si la búsqueda de RESA15 en el backend devuelve datos o un resultado vacío.
4 Revisar el comando 'cotizaciones.commands.js' en la línea 231 para entender por qué se espera 'span.glyphicon-refresh' en este punto del flujo.
