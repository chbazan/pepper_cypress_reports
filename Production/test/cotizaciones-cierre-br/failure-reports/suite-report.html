Fallo al buscar cotización RESA15 en UI de cotizaciones de securities

Descripción detallada

El test 'Guardar la cotización de cierre del ticker RESA15' intenta buscar y guardar una cotización. El fallo ocurrió después de que el test ingresara 'RESA15' en el campo de búsqueda, seleccionara la opción del dropdown y hiciera clic en el botón 'Buscar'. La evidencia muestra que la tabla de resultados permanece vacía y el test lanza un error personalizado indicando que 'No se encontró RESA15 después de 5 intentos'. El HAR no reporta errores de red (4xx/5xx) ni requests lentos.

Posibles causas

ALTA
Ticker RESA15 no existe o no está disponible para la fecha seleccionada
El mensaje de error 'No se encontró RESA15' y la tabla vacía en la UI, sin errores de red, sugieren que la búsqueda no devuelve datos para este ticker en particular o para la fecha del test (24/06/2020, visible en el video).
MEDIA
Problema de sincronización o renderizado de datos en la UI
Aunque la API no reporta errores, podría haber un problema en cómo la UI procesa la respuesta de la API o en su lógica de renderizado, impidiendo que el dato aparezca en la tabla.
BAJA
Error en la lógica de búsqueda del comando Cypress
El video muestra que las acciones de typing y click se ejecutan correctamente. El fallo se produce en la verificación posterior de la existencia del elemento en la tabla, lo que indica que el problema no es la interacción inicial.

Pasos de Troubleshooting

1 Verificar manualmente en el ambiente production/br-gs32 si el ticker RESA15 se puede buscar y aparece en la tabla de 'Administrar cotizaciones de securities' para la fecha del test (24/06/2020).
2 Inspeccionar las llamadas de red (HAR) en el navegador durante la búsqueda manual para ver la respuesta de la API al buscar RESA15 y confirmar si contiene datos.
3 Revisar los logs del backend para la API de cotizaciones de securities en production para ver si hay errores al intentar buscar RESA15.
4 Ejecutar el test localmente con TARGET_ENV=production TARGET_CLIENT=br-gs32 MODE=only SPEC=cotizaciones_cierre_br npm run test para intentar reproducir el fallo.
