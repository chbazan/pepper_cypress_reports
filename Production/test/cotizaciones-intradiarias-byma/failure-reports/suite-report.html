Fallo de login GS32: cy.visit a admin.mercapabbaco.com recibió content-type 'undefined'

Descripción detallada

El test intentaba realizar el login a la aplicación Pepper. Después de ingresar las credenciales en la página de Auth0 y hacer clic en 'Continue', el navegador fue redirigido a 'https://admin.mercapabbaco.com/administrative'. Sin embargo, la navegación falló porque la respuesta del servidor para esta URL tuvo un 'content-type' indefinido, en lugar del esperado 'text/html'. El video muestra una pantalla blanca durante más de un minuto, indicando que la página nunca se cargó correctamente. La duración del test (132 segundos) excede significativamente el 'pageLoadTimeout' por defecto.

Posibles causas

ALTA
Servidor de aplicación no disponible/mal configurado
El error 'content-type: undefined' en la respuesta de cy.visit a 'admin.mercapabbaco.com' es una indicación fuerte de que el servidor no está respondiendo correctamente o no está sirviendo el contenido esperado.
MEDIA
Redirección Auth0 incorrecta
Aunque el login de Auth0 parece completarse, la URL final de redirección a la aplicación ('admin.mercapabbaco.com') podría estar mal configurada en Auth0, apuntando a un recurso inexistente o inaccesible.
MEDIA
Problema de infraestructura/red en production
La larga duración del test (132s) y la falta de una respuesta con content-type válido sugieren que un problema de red o infraestructura está impidiendo que el navegador reciba una respuesta HTTP completa del servidor de la aplicación.

Pasos de Troubleshooting

1 Abrir 'https://admin.mercapabbaco.com/administrative' manualmente en un navegador en el ambiente de production para verificar si la página carga correctamente.
2 Verificar los logs del servidor de 'admin.mercapabbaco.com' en el ambiente de production para buscar errores relacionados con la carga de la página o el content-type.
3 Revisar la configuración de Auth0 para el cliente 'arg-gs32' en production para asegurar que la URL de callback y los dominios permitidos sean correctos.
4 Reproducir el spec fallido localmente con `TARGET_ENV=production TARGET_CLIENT=arg-gs32 MODE=only SPEC=cotizaciones_intradiarias_byma.cy.js npm run test` para observar el comportamiento en tiempo real.
5 Consultar al equipo de DevOps/Infraestructura sobre posibles problemas de despliegue o disponibilidad del servidor 'admin.mercapabbaco.com' en production.
