Mismatch de cotización de cierre para bono TX28 en Investments

Descripción detallada

El test 'Inversión del bono TX28 con la cotización de cierre esperada' ejecutaba la validación de la cotización de cierre del bono TX28. Falló en el paso de aserción, donde se esperaba que el valor de la cotización fuera cercano a 1680.5 (con una tolerancia de +/- 2), pero se obtuvo 1690.5. La duración del test fue muy corta (1134ms), indicando un fallo rápido de aserción. No se observaron errores de red ni timeouts en el HAR.

Posibles causas

ALTA
Mismatch de cotización en la API de Investments
El error es un AssertionError directo sobre un valor numérico ('expected 1690.5 to be close to 1680.5 +/- 2'). El test valida contra la API de Investments, y la red no mostró errores, lo que sugiere que la API devolvió un valor diferente al esperado por el test.
MEDIA
Valor esperado desactualizado en el test
Es posible que el valor '1680.5' en el test sea una cotización antigua o incorrecta, y '1690.5' sea el valor correcto actual de la API para el bono TX28.
BAJA
Error de cálculo en el comando Cypress
Un error en la lógica de cálculo dentro del comando Cypress en 'cotizaciones.commands.js' que obtiene o procesa el 'moneyAmount' podría llevar a un valor incorrecto antes de la aserción.
