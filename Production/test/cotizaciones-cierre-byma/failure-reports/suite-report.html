Descripción detallada

El test 'Valuación del bono YMCWO con la cotización de cierre esperada' estaba ejecutando una validación de datos. Posibles causas

ALTA
Datos de test desactualizados o incorrectos para YMCWO
El test busca un bono específico (YMCWO) con una fecha (2026-07-01). Si el bono no existe para esa fecha o su shortName ha cambiado en el sistema, la API no lo devolverá. El error es una aserción de datos, no de red o UI.
MEDIA
Problema en la configuración o disponibilidad del bono YMCWO en el ambiente
Aunque la API respondió con 200, es posible que el bono YMCWO no esté configurado correctamente o esté inactivo en el ambiente de production/arg-gs32 para la fecha solicitada, impidiendo que aparezca en tradable-securities.
BAJA
Bug en la API tradable-securities que filtra incorrectamente los bonos
Menos probable dado que la API respondió con 200 y no hay otros errores de red, pero podría haber un error lógico interno que impide la inclusión de YMCWO en la respuesta.
