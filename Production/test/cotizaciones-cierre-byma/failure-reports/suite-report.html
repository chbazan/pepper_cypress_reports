Timeout al buscar dropdown de sugerencias para ticker AL30D en cotizaciones de securities.

Descripción detallada

El test 'Guardar la cotización de cierre del ticker AL30D' intentaba validar la funcionalidad de cotizaciones de cierre. El fallo ocurrió al intentar obtener el elemento `ul.typeahead.dropdown-menu` después de ingresar el ticker 'AL30D' en el campo de búsqueda. A pesar de que el video muestra el dropdown de sugerencias visible en la UI después de la entrada, Cypress no pudo encontrar el elemento dentro del tiempo de espera de 10 segundos. No se observaron errores de red (4xx/5xx) ni requests lentos en el HAR asociados al momento del fallo.

Posibles causas

ALTA
Elemento no presente en el DOM durante el `cy.get`
El mensaje de error 'Expected to find element... but never found it' es explícito. Aunque el video muestra el elemento, es posible que haya un re-renderizado o un timing que lo haga desaparecer brevemente, causando el timeout de 10 segundos.
MEDIA
Selector incorrecto o demasiado genérico
Si el selector `ul.typeahead.dropdown-menu` no apunta al elemento exacto que Cypress espera, o si hay múltiples elementos con ese selector y el deseado no es el primero, podría causar el fallo. Sin embargo, el video sugiere que el elemento visualmente correcto sí aparece.
BAJA
Interferencia de otro elemento o overlay
Aunque el video no muestra un overlay obvio, a veces elementos superpuestos pueden impedir que Cypress 'vea' el elemento subyacente, incluso si está en el DOM. Esto es menos probable con un error de 'never found it', pero posible si el DOM es complejo.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente en el ambiente de `production/arg-gs32` para observar el comportamiento en tiempo real: `TARGET_ENV=production TARGET_CLIENT=arg-gs32 MODE=only SPEC=cotizaciones_cierre_byma npm run test`
2 Abrir la aplicación manualmente en `https://admin.mercapbabbaco.com/administrative` y navegar a 'Administrar cotizaciones de securities'. Intentar buscar 'AL30D' para verificar si el dropdown de sugerencias aparece consistentemente.
3 Inspeccionar el DOM en el momento de la búsqueda de 'AL30D' para confirmar la existencia y el selector exacto del `ul.typeahead.dropdown-menu`.
4 Revisar el código en `cypress/support/commands/cotizaciones.commands.js:220` para entender el contexto exacto del `cy.get` y si hay alguna condición que pueda afectar la presencia del elemento.
