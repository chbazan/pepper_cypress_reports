Descripción detallada

El test 'Guardar la cotización de cierre del ticker LECHO' estaba ejecutando el flujo de administración de cotizaciones de securities. El fallo ocurrió cuando Cypress intentó localizar el elemento 'span.glyphicon-refresh', agotando el tiempo de espera de 60000ms. El video muestra que, tras buscar el ticker 'LECHO', la tabla de resultados indicaba 'No hay información para mostrar', y el elemento 'span.glyphicon-refresh' no era visible en la UI. No se observaron errores o lentitud en las peticiones de red.

Posibles causas

ALTA
Elemento 'span.glyphicon-refresh' no renderizado
El error literal 'Expected to find element: `span.glyphicon-refresh`, but never found it' y el timeout de 60000ms indican que Cypress buscó el elemento sin éxito. El video y screenshot confirman que no estaba visible en la UI. Podría ser un spinner que no apareció o un cambio en la UI que eliminó el selector.
MEDIA
Datos no encontrados para el ticker LECHO
La UI muestra 'No hay información para mostrar' para LECHO. Si el 'glyphicon-refresh' es un indicador de carga de datos, su ausencia podría ser una consecuencia de que no hay datos para cargar, y el test esperaba que apareciera incluso en ese escenario.
MEDIA
Error en la lógica del test
Si el comando era 'cy.get('span.glyphicon-refresh').should('not.exist')' (como sugiere el log de Cypress en el video), el test debería haber pasado si el elemento nunca fue encontrado. El fallo con 'Expected to find element... but never found it' en este contexto indica una posible inconsistencia en Cypress o un uso inadecuado del comando para la aserción de no existencia.

3 Revisar el código del test en cypress/support/commands/cotizaciones.commands.js línea 231 para entender la intención exacta del comando 'cy.get('span.glyphicon-refresh')'.
4 Verificar en los logs de la aplicación o de la API de cotizaciones si hay errores relacionados con el ticker 'LECHO' o la carga de datos.
