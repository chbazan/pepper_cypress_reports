Descripción detallada

El test ejecutaba la validación de cotizaciones de cierre ByMA en el módulo de Investments. Falló en el paso de aserción del valor de inversión del bono LECHO, donde se esperaba un valor cercano a 28800 pero se obtuvo 28000. La evidencia del video y HAR muestra que la API de Investments respondió exitosamente con un POST 201, indicando que el valor 28000 fue recibido o calculado a partir de esa respuesta. La UI de administración de cotizaciones estaba visible y la duración de 1323ms indica una ejecución rápida sin timeouts.

Posibles causas

ALTA
Datos de cotización desactualizados
El test espera un valor específico (28800) que podría estar desactualizado, mientras que la API o el cálculo actual produce 28000. Esto es común si las cotizaciones de cierre cambian y los valores esperados en los tests no se actualizan.
MEDIA
Error en la lógica de cálculo de inversión
Aunque la API de Investments respondió con un status 201, el valor 28000 podría ser incorrecto debido a un bug en el backend que realiza el cálculo de la inversión para el bono LECHO.
MEDIA
Valor esperado en el test incorrecto
El valor 28800 +/- 2 podría ser un valor hardcodeado o un fixture desactualizado en el código del test, que ya no es válido para el bono LECHO en el ambiente de producción.
