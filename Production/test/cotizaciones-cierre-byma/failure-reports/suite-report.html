Descripción detallada

El test intentaba guardar la cotización de cierre del ticker LECHO en el módulo de Cotizaciones de Securities. Falló al esperar el elemento 'span.glyphicon-refresh', que no fue encontrado en el DOM tras 60000ms. La duración total del test fue de 139794ms, indicando que el proceso se extendió significativamente antes del timeout del comando. El HAR no reporta errores de red ni requests lentos.

Posibles causas

ALTA
TIMEOUT DE ELEMENTO
El mensaje de error indica directamente que el selector 'span.glyphicon-refresh' no se encontró en el DOM dentro del 'defaultCommandTimeout' de 60s.
ALTA
Cambio de UI / Componente no renderizado
El elemento esperado ('span.glyphicon-refresh') podría haber sido eliminado o renombrado en un cambio reciente de la UI, o un bug impide su renderizado en el flujo de guardado de cotizaciones.
MEDIA
Paso previo fallido silenciosamente
Aunque no se reportan errores de red, un fallo en un paso anterior (ej. el POST para guardar la cotización) podría haber dejado la UI en un estado donde el 'glyphicon-refresh' nunca se activa o se espera.
BAJA
Estado de carga (spinner) que no se ocultó
A pesar de que el HAR no reporta requests lentos, la UI podría estar experimentando un retraso en la actualización de su estado, lo que impide que el elemento de refresh aparezca o desaparezca a tiempo.
