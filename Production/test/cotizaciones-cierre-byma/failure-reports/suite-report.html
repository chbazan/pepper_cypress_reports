Descripción detallada

El test "Inversión del bono LECHO con la cotización de cierre esperada" estaba validando la cotización de cierre del bono LECHO en el módulo de "Administrar cotizaciones de securities" de ByMA Admin, comparando el valor con la API de Investments. El fallo ocurrió en un paso de aserción, donde se esperaba un valor cercano a 28800 (+/- 2) pero se recibió 28000. El video muestra la interfaz de usuario cargada correctamente y el HAR no reporta errores de red ni latencia excesiva en las llamadas a las APIs de Appraiser o Investments.

Posibles causas

ALTA
Datos de cotización desactualizados en la API de Investments.
El valor recibido (28000) difiere significativamente del esperado (28800), lo que sugiere que la cotización del bono LECHO en la API de Investments no se corresponde con el valor de referencia del test.
MEDIA
Error en la lógica de cálculo del valor esperado en el test.
Podría haber un error en la implementación del comando `cotizaciones.commands.js` que define el valor esperado para el bono LECHO, o en cómo se procesa el valor de la API.
BAJA
Problema de redondeo o precisión en la API o el test.
Aunque la diferencia es grande (800), un error de precisión o redondeo en la API o en el test podría, en casos raros, causar una discrepancia.

Pasos de Troubleshooting

1 Reproducir el spec fallido localmente en `production/arg-gs32` para confirmar el error.
2 Verificar el valor de cierre del bono LECHO para la fecha `2026-05-25` directamente en la API de Investments (e.g., `GET /api.mercapabbaco.com/investments/{id}/metrics` con el ID de inversión correspondiente a LECHO).
3 Revisar el código en `cypress/support/commands/cotizaciones.commands.js` en la línea 757 para entender cómo se obtiene y se compara el valor de la cotización.
4 Comparar el valor obtenido de la API con el valor esperado en el test y con el valor mostrado en la UI de Pepper para el bono LECHO.
