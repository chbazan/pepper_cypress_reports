El test estaba validando la cotización de cierre esperada para el bono YMCWO contra la API de Investments en el panel de ByMA Admin. El fallo ocurrió en el paso de aserción, donde el valor de inversión recibido fue 0, mientras que el test esperaba un valor cercano a 148000. Posibles causas

ALTA
Datos incorrectos en la API de Investments
El HAR indica que no hubo fallos de red, lo que sugiere que la API respondió exitosamente pero con un valor de 0, en lugar del esperado 148000.
ALTA
Error de cálculo en el backend (Appraiser/Investments)
Si la API devuelve 0, es probable que haya un error en la lógica de cálculo del valor de inversión del bono YMCWO en los servicios de backend.
MEDIA
Valor esperado desactualizado en el test
Es posible que el valor de 148000 esperado en el test sea obsoleto y el valor actual de 0 sea correcto, o que el valor real sea diferente a ambos.
BAJA
Error de extracción de datos de la UI
Aunque el error apunta a una aserción de valor, si el test extrae el valor de la UI, podría haber un error en el selector o en el procesamiento que resulta en 0.
