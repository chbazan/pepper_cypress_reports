El test ejecutaba la validación de la cotización de cierre para el bono YMCWO, comparando los datos del Admin de Pepper contra la API de Appraiser. El fallo ocurrió durante la validación de datos, después de una llamada exitosa a la API 'tradable-securities'. La evidencia del HAR y el mensaje de error confirman que la API respondió con un status 200, pero el payload de la respuesta no contenía la información esperada para el bono 'YMCWO', lo que provocó que una aserción custom en el código del test fallara.

Posibles causas

ALTA
Datos del bono YMCWO ausentes en la respuesta de la API `tradable-securities`.
El mensaje de error 'No se encontró un item con shortName=YMCWO en la respuesta de tradable-securities' es una excepción controlada por el test, lo que confirma que la API respondió pero sin los datos esperados. El HAR muestra 0 requests fallidas.
MEDIA
El bono YMCWO fue deslistado o marcado como inactivo en el backend.
La API podría estar funcionando correctamente al filtrar instrumentos que ya no están activos o no tuvieron cotización en la fecha consultada. El test, sin embargo, aún espera que el bono esté presente.
BAJA
Inconsistencia de datos entre la UI de Pepper y la API de Appraiser.
Es posible que la UI y la API consulten fuentes de datos diferentes o con distinta sincronización, mostrando el bono en un lado pero no en el otro. El fallo en la API sugiere que esa es la fuente del problema.
