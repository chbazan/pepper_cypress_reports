El error 'expected 1691 to be close to 1699 +/- 2' indica una diferencia numérica directa. El HAR no muestra errores de red, por lo que la API respondió, pero el valor no coincide con lo esperado.
MEDIA

Si el valor real de la cotización del bono TX28 cambió recientemente, el valor esperado en el test (1699) podría no haberse actualizado, llevando a la aserción a fallar contra el valor actual (1691).
BAJA

Aunque el HAR no reporta errores, podría haber un bug en la lógica de cálculo de la cotización de cierre en el frontend o en una capa intermedia que no se refleja como un error de red.
